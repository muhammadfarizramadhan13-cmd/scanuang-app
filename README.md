# MoneyScan

Aplikasi web pemindaian uang berbasis React/Vite.

## Fitur

- Kamera perangkat menggunakan MediaDevices API
- Upload foto dari perangkat
- Pemilihan mata uang: IDR, USD, EUR, dan SGD
- Input nominal manual
- Penyimpanan hasil sementara di riwayat sesi
- Tampilan responsif gaya kasir/mobile

## Jalankan secara lokal

```bash
npm install
npm run dev
```

## Build produksi

```bash
npm run build
```

> Versi ini tidak menggunakan AI dan tidak memverifikasi keaslian uang.
